2. PROJECT OVERVIEW
================================================================================

The AI-Powered Product Strategy Assistant is a multi-agent AI system designed
to help Product Managers transform raw sales and customer data into actionable
strategic insights. Instead of spending hours manually analysing spreadsheets,
a Product Manager can upload their data and receive a complete strategic
analysis — including SWOT, opportunity scores, a quarterly roadmap, and an
executive report — in under two minutes.

The system is built around a sequential pipeline of 8 specialised AI agents,
each powered by OpenAI GPT-4o Mini. Each agent focuses on a specific aspect of
product strategy, passes its findings to the next agent, and together they build
a comprehensive picture of the business.

The pipeline is sequential: each agent receives the full data summary plus the
combined outputs of all previous agents, so later agents (e.g. Roadmap,
Executive Report) have complete context from all earlier analysis.

5. AGENT DESCRIPTIONS
================================================================================

  Agent 1 — Data Analysis Agent
    Role    : Analyses the CSV sales data — revenue, profit, units sold,
              regional performance, product rankings, and trend lines.
    Input   : Raw CSV summary statistics
    Output  : Bullet-pointed insights with specific figures and percentages

  Agent 2 — Customer Feedback Agent
    Role    : Performs sentiment analysis on the customer review column.
              Identifies recurring pain points, positive drivers, and
              satisfaction patterns by product and category.
    Input   : Data summary + Agent 1 output
    Output  : Sentiment themes and NPS-style implications

  Agent 3 — Market Opportunity Agent
    Role    : Identifies growth opportunities, underserved segments,
              cross-sell potential, and regional expansion plays.
    Input   : Data summary + Agents 1-2 outputs
    Output  : Prioritised list of market opportunities

  Agent 4 — SWOT Analysis Agent
    Role    : Produces a data-grounded SWOT analysis (Strengths, Weaknesses,
              Opportunities, Threats). Every bullet is linked to evidence
              from the actual data.
    Input   : Data summary + Agents 1-3 outputs
    Output  : Structured SWOT with 4-6 bullets per quadrant

  Agent 5 — Feature Prioritization Agent
    Role    : Recommends product improvements and new features using the
              MoSCoW framework (Must-Have, Should-Have, Nice-to-Have)
              plus a top-3 Quick Wins list.
    Input   : Data summary + Agents 1-4 outputs
    Output  : Prioritised feature backlog

  Agent 6 — Opportunity Scoring Agent
    Role    : Scores each product on four dimensions (Market Opportunity,
              Financial Attractiveness, Customer Demand, Competitive Position)
              and assigns an Overall Score (1-10) and a recommendation
              (Invest / Maintain / Optimise / Divest).
    Input   : Data summary + Agents 1-5 outputs
    Output  : Scoring matrix table + narrative on top 3 opportunities

  Agent 7 — Roadmap Generation Agent
    Role    : Creates a realistic quarterly product roadmap (Q1-Q4) with
              themes, key initiatives, success metrics, and dependencies
              grounded in all prior analysis.
    Input   : Data summary + Agents 1-6 outputs
    Output  : Structured Q1-Q4 roadmap

  Agent 8 — Executive Report Agent
    Role    : Synthesises all seven agents' outputs into a C-suite-ready
              executive summary including Key Findings, Strategic
              Recommendations, a 30-60-90 Day Action Plan, and
              Success Metrics.
    Input   : Data summary + Agents 1-7 outputs
    Output  : Complete executive report

6. HOW THE APPLICATION WORKS (USER FLOW)
================================================================================

  Step 1 — Open the app
    Navigate to https://sampy-3jhr.onrender.com/
    The sample sales dataset (Sample Sales Data.csv) loads automatically.

  Step 2 — Review key metrics
    The top of the page shows five headline metrics:
    Total Revenue, Total Profit, Units Sold, Average Rating, Returns.

  Step 3 — Run the analysis
    Click "Run Full Analysis (8 agents)".
    A progress bar shows each agent running in sequence.
    The full pipeline completes in approximately 60-90 seconds.

  Step 4 — Explore results
    Results appear across 8 tabs:
      Tab 1 — Data Overview      : 4 interactive Plotly charts + data analysis
      Tab 2 — Customer Insights  : Sentiment themes and pain points
      Tab 3 — Market Opportunities: Growth plays and expansion ideas
      Tab 4 — SWOT Analysis      : Data-grounded four-quadrant analysis
      Tab 5 — Feature Priorities : MoSCoW framework recommendations
      Tab 6 — Opportunity Scores : Per-product scoring matrix
      Tab 7 — Product Roadmap    : Q1-Q4 quarterly plan
      Tab 8 — Executive Summary  : C-suite action plan

  Step 5 — Download reports
    Click "Download PDF Report" to get the full branded executive report.
    Click "Download Architecture Diagram" to get the system diagram PNG.

  Step 6 — Chat with the assistant
    Use the chat box at the bottom to ask follow-up strategy questions.
    The assistant answers using all 8 agents' outputs as context.
    Example questions:
      "Which product should we focus on in Q2?"
      "What are the top 3 risks in our portfolio?"
      "Which region has the highest growth potential?"

  Step 7 — Monitor the pipeline
    Expand "Pipeline Monitor" to see tokens used and time taken per agent.

10. SETUP AND LOCAL RUN
================================================================================

  Prerequisites: Python 3.11+, pip

  1. Clone the repository:
       git clone https://github.com/praveenkarthick108-arch/sampy.git
       cd sampy/Assignment

  2. Install dependencies:
       pip install -r requirements.txt

  3. Configure environment:
       Copy .env.example to .env and fill in your API key.

  4. Run the app:
       streamlit run app.py

  5. Open http://localhost:8501 in your browser.
